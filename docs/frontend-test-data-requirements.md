## 回归记录要求

- 记录接口是否 `code=1`。
- 记录页面是否展示真实数据或合理空态。
- 记录控制台是否有 error。
- 写操作必须记录生成的业务 ID。
- 后端业务错误不算前端通过，需标注为环境/数据/接口阻塞。
