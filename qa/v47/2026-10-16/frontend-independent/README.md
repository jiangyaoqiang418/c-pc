## 已修改

1. **公共弹层回到原型的过渡规则。** 商品分享、评价配图、账户、地区及BusinessDialog统一使用原型已有`modal` Vue Transition与冻结CSS。移除另一套开/关关键帧；遮罩与内容嵌套，使用原型flex居中/700px以下底部对齐，避免中心定位transform与入场位移竞争。全图预览仍保持原先无额外入场动效。
2. **公共弹窗卸载清理。** 异步确认/取消检查在卸载后失效，不再弹出上个组件的迟到错误。既有`page.test.ts`新增两项真实setup回归；修改前两项均因过期提示失败，修改后通过。
3. **图片预览键盘。** 初始焦点在关闭按钮时，原左右键事件无法到达内部图片容器。现在由弹窗内容转发键盘事件，预览在整个弹窗内响应左右键，不改变按钮、图片和计数外观。Chrome实测初始`1 / 2`→Right后`2 / 2`→Left后`1 / 2`，Escape关闭。
4. **非MEME配色的关闭按钮边框。** 浅色方案原残留MEME的`rgb(70,86,56)`绿色边框；只改为各配色的`--line`，MEME保持不变，不修改边框宽度、形状、背景或文字尺寸。
5. **本地验收入口。** 既有DEV入口增加`?view=components`，提供公共弹窗、两图预览和金额输入；`?view=gallery`增加仅用于验收的快速开关按钮。使用已有只读资产、独立Pinia和内存路由，不进入生产入口，不执行商品/订单/资金写入，不保存账号或改变其他标签的配色。

没有新增或升级依赖，没有改包/锁文件、17份冻结参考CSS、原型目录、主题元数据、生产素材或H5。修改位于现有Vue/Reka工程，不添加另一套UI/动画库。
