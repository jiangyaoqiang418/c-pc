# 配色与布局解耦

2026-10-16，按用户要求固定默认MEME布局，27套方案只切换配色。范围为c-pc及同一套手机响应式页面，独立c-h5未修改。

## 实现边界

- `data-ui-theme`作为冻结参考CSS的兼容布局入口固定为web3-meme，`data-ui-layout=v47`标记统一布局；实际配色由`data-ui-palette`控制。`useUiTheme().currentTheme`和原localStorage键仍表示实际配色，保存、刷新与跨标签同步继续沿用原流程。
- 首页内容结构、图标及手机抽屉拖拽统一使用默认布局，不再随着配色切换另一套首页/图标/弹层。各断点宽度、间距、字体、动画及原始素材沿用默认版；官方Logo和手机聚焦修复继续保留。
- `scripts/generate-v47-palette-css.mjs`仅从既有基础样式、色板别名及冻结级联提取颜色/色彩方案/颜色变量，生成`umaomao-palette-v47.css`；边框简写只提取颜色，不复制边框宽度，排除字体、尺寸、圆角、阴影等布局变量，不加载另一套主视觉图片。
- `umaomao-palette-adapters.css`仅补充MEME专属区域的语义颜色：主视觉、文字、按钮、商品卡、手机导航、钱包和弹层。默认MEME不进入这些覆盖，猫咪等原始图形不重染。浅色底衬不再保留默认的深色硬编码导致深字深底。
- 17份原始参考CSS、129个素材、50条只读参考商品及27套方案元数据未改；未新增或升级依赖，包与锁文件未改。配色层不得手工增加尺寸声明；源样式变化后运行生成脚本，再执行`node scripts/generate-v47-palette-css.mjs --check`。
